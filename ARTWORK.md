# Локальные иллюстрации в версии 0.7.1

Новые изображения являются оригинальными векторными SVG, подготовленными для этого расширения. Все они загружаются локально и не требуют внешних ресурсов:

- `art/pink-scene.svg` — школьный коридор, тёплые окна, сакура.
- `art/gothic-scene.svg` — полночный особняк, витражи, свечи.
- `art/retro-scene.svg` — двор девяностых, панельные дома, гаражи, качели и кассета.
- `art/xianxia-scene.svg` — горы, павильон, фонари и бамбук.
- `art/sacred-scene.svg` — исторический собор, роза-витраж и свечи.

Декоративные SVG старых версий в `art/` и `rose.svg` сохранены для совместимости с имеющимися CSS-правилами. Текст оформляется семействами с запасными системными вариантами. CSS может подгружать декоративные семейства с Google Fonts через HTTPS при наличии интернета, но шрифтовых файлов в архиве нет и фоны остаются полностью локальными.

Рисунки не содержат данных о персонажах и не подменяют загруженные пользователем PNG. Для экономии ресурсов вместо тяжёлых растровых полноэкранных изображений используются статичные векторные сцены.
