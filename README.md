# Quiet Tavern Companion · Тихая таверна

**Версия 0.7.22** · расширение для SillyTavern в стиле визуальной новеллы.

Интерфейс с персонажем и пятью оформлениями: **Лепестки весны** (сакура), **Полуночный вальс** (готика), **Кассетное лето** (90-е), **Нити судьбы** (сянься) и **Золотой час** (обитель). Внутри есть смена PNG-эмоций, отдельная память истории, система отношений и настройки модели.

## Установка

В SillyTavern открой **Extensions → Install Extension**, затем вставь:

`https://github.com/bigbob6767/quiet-tavern-companion`

Либо установи содержимое ZIP как папку `quiet-tavern-companion` в каталог сторонних расширений. Перед обновлением рекомендуется сделать резервную копию через **Настройки → Память и приватность**. Не очищай данные браузера: именно там могут храниться PNG и память.

## Что исправлено в 0.7.22

- Убран полноэкранный фон диалога, накладывавшийся на основной чат SillyTavern.
- Убрана полупрозрачная подложка встречи за персонажем, в том числе со старыми сохранёнными настройками.
- Фоны оставлены только в стартовом меню. Центральная компоновка и защита PNG от выхода за границы сохранены.
- Убраны две плавающие кнопки «Настройки / Свернуть», дублировавшие управление диалогом. Настройки остались в шапке диалогового окна и в меню расширений.
- Свёрнутый разговор показывается маленькой кнопкой компаньона вместо огромной PNG посреди чата.

## Исправления предыдущих версий

- Перестроено окно разговора: имя и эмоциональные статусы не перекрывают друг друга, крестик всегда справа.
- Поле ответа теперь закреплено внизу окна и доступно без раскрытия списка действий.
- Длинные реплики прокручиваются отдельно; показатели отношений свёрнуты и раскрываются по нажатию.
- Настройки имеют читаемые заголовки и вкладки, работающие на узких экранах.
- Убраны сотни фиксированных SVG-картинок вместо слов на кнопках: именно они съезжали из рамок. Кнопки и вкладки снова используют живой текст.
- Декоративные рамки, сцены, пять основных тем, PNG-эмоции, отношения и генерация ответов сохранены.

## Типографика

Все подписи интерфейса — настоящий текст с аккуратными системными гарнитурами, подходящими к теме. Для крупных названий историй оставлены статические декоративные SVG-эмблемы. Интерфейс больше не накладывает SVG-картинки на динамические слова. Точные Luna Morta и Game Paused не входят в расширение, и загрузка шрифтов пользователем не нужна.

## Обновление на GitHub

Замени содержимое репозитория файлами этой версии. Обрати внимание: обычная загрузка новых файлов на сайте GitHub не удаляет устаревшие. Старые CSS (`base.css`, `skins.css`, `polish.css`, `novella.css`, `ornate.css`, `interface-076.css`, `mobile-fixes-079.css`) и неиспользуемые SVG можно удалить вручную; новая версия обращается только к `style.css` и пяти актуальным наборам арта.

## Проверка

В этой сборке прошли автоматические проверки. Поведение в конкретных браузерах, версиях SillyTavern и подключениях к моделям может отличаться.
